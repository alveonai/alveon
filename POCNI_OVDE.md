# Projekat: foto-štand „Uđi u igru” (GTA event, Ušće, 18. 11. 2026)

Sve za projekat je u ovom folderu.

| Šta | Gde |
|---|---|
| **Aplikacija** (kod) | `gta-booth/` |
| **Plan aplikacije** (sve odluke, arhitektura, rizici) | `gta-booth/PLAN.md` |
| **Lokalno testiranje, korak po korak** | `gta-booth/TESTIRANJE.md` |
| **Postavljanje na Cloudflare i kontrolna lista za event** | `gta-booth/README.md` |
| **Odgovor nezavisnog recenzenta** (na plan v1) | `gta-booth/docs/recenzija-1.md` |
| **Snimci ekrana** (telefon i tablet) | `gta-booth/docs/snimci-ekrana/` |
| Prompt za AI | `gta-booth/src/prompt.js` |
| Podešavanja (limit, rokovi brisanja, model…) | `gta-booth/wrangler.toml` |

`index.html` u ovom folderu je postojeći Alveon sajt iz repozitorijuma; nije deo
foto-štanda.

Git: ovaj folder je git repozitorijum (skriveni `.git` folder) sa celom istorijom,
grana `claude/gta-event-photo-automation-i793ak`. Još nije povezan sa GitHub-om.
